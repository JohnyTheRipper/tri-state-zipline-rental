# Analytics Setup

The app includes `dataLayer` events for:

- `proposal_form_started`
- `proposal_form_submitted`
- `phone_clicked`
- `email_clicked`
- `video_clicked`
- `gallery_filter_clicked`

## Production Credentials Needed

- Google Analytics 4 measurement ID
- Google Search Console verification
- Meta Pixel ID
- Calendly URL
- CRM webhook URL
- AI chatbot embed or SDK

Do not hardcode production IDs until the owner approves the tracking stack and consent requirements.

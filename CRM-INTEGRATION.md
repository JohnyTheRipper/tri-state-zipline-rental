# CRM Integration

`data/proposals.json`

Supported future integrations:

- HubSpot
- GoHighLevel
- Zoho
- Salesforce
- Mailchimp
- ActiveCampaign
- Zapier
- Make
- Generic webhook

Fields already captured include organization, contact, email, phone, event date, event type, budget, location, attendance, package interest, UTM source, UTM medium, UTM campaign and landing page.

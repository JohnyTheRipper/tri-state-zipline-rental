# Admin Guide

This is a Node.js app, not WordPress.

## Main Content File

Edit most site content in:

`src/data.js`

This includes:

- Business name
- Taglines
- Phone
- Email
- Packages
- Audience pages
- SEO landing pages
- FAQs
- Gallery categories
- Video categories
- Blog launch topics

## Page Templates

Edit layouts in:

`src/render.js`

## Styling

Edit design in:

`public/styles.css`

## Browser Interactions

Edit navigation, form submission, tracking hooks and video controls in:

`public/app.js`

## Proposal Leads

Submitted proposal requests save to:

`data/proposals.json`

Back this file up regularly.

## Media

Put images in:

`public/assets`

Put videos in:

`public/media`

Hero video filenames expected by the homepage:

- `public/media/homepage-hype-desktop.mp4`
- `public/media/homepage-hype-mobile.mp4`
